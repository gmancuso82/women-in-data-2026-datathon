# Colombia SIPSA pilot workspace

This is a safe working copy for the Women in Data datathon pilot. It turns four official DANE/SIPSA daily workbooks into a tidy local wholesale-price table for Bogota Corabastos and Medellin CMA.

The output is a fresh-food market-price proxy, not an official retail Cost of a Healthy Diet (CoHD) estimate.

Selected source dates: 12 February, 14 May, 13 August, and 12 November 2025.
