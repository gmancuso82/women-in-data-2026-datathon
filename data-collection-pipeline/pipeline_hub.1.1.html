2 Extract a paper scan

Run from a terminal, in this folder. Swap in the country's fieldmap and the actual scan filename(s).
terminal
python3 forms/extract_paper_form.1.5.py <scan.pdf> forms/hoos_cooking_paper_form_COL.1.2_fieldmap.json schema/hoos_cooking_form_schema.1.2.json <output_basename>
terminal
python3 forms/extract_paper_form.1.5.py --batch <folder_of_scans> forms/hoos_cooking_paper_form_COL.1.2_fieldmap.json schema/hoos_cooking_form_schema.1.2.json <output_basename>
Produces <output_basename>_submissions.csv and _line_items.csv. Use the NGA fieldmap for a Nigeria form; a batch folder must be all one country. Add --model models/checkbox_classifier.1.0.pkl --digit-model models/digit_classifier.1.0.pkl to use the trained classifiers instead of the built-in defaults — optional, see Retrain below.

3 Generate a review page

Two commands: first export the crops + manifest, then turn that into one HTML page a reviewer opens directly (no terminal from there on).
terminal — step 3a
python3 forms/extract_paper_form.1.5.py --review <scan.pdf> forms/hoos_cooking_paper_form_COL.1.2_fieldmap.json schema/hoos_cooking_form_schema.1.2.json <review_out_dir>
terminal — step 3a
python3 forms/extract_paper_form.1.5.py --review --batch <folder_of_scans> forms/hoos_cooking_paper_form_COL.1.2_fieldmap.json schema/hoos_cooking_form_schema.1.2.json <review_out_dir>
terminal — step 3b
python3 forms/build_review_tool.1.2.py <review_out_dir>/review_manifest_<form_id>.csv <review_page.html>
terminal — step 3b
python3 forms/build_review_tool.1.2.py <review_out_dir> <review_page.html>
Then open <review_page.html> in any browser. A folder run combines every scan into one page, each with its own "are all other lines blank?" shortcut. See demo/demo_review.html for a filled-in example.

4 Ingest the reviewer's corrections

After downloading the corrected CSV from the review page:
terminal
python3 forms/extract_paper_form.1.5.py --ingest <corrected_manifest.csv> labels/
Appends to checkbox_labels.csv and price_labels.csv — the growing dataset the classifiers in the next step train on.

5 Retrain the classifiers

Run anytime after ingesting new corrections, to fold them into the models. Each prints an honest accuracy estimate before saving.
terminal — checkboxes
python3 forms/train_checkbox_classifier.1.0.py labels/checkbox_labels.csv models/checkbox_classifier.1.0.pkl
terminal — prices
python3 forms/train_digit_classifier.1.0.py labels/price_labels.csv models/digit_classifier.1.0.pkl
The updated .pkl files are used automatically next time you pass --model / --digit-model in step 2 or 3.
Implementation notes
Checkbox/price geometry — auto-located, no manual calibration Star-mark detection — validated on a real scan, 5/5 Handwritten price OCR — classifier helps, still far from reliable Header field OCR — unreliable, not addressed yet Write-in item names — unreliable, needs a bigger model than this pipeline uses Running the scripts — needs Python + a terminal, no click-through app yet
  • hoos_cooking_form_schema.1.2.json — single source of truth for food groups, item lists, output shape
  • Pipeline scripts (extract_paper_form.*.py, build_review_tool.*.py, train_*.py) are versioned by filename in this same folder; each docstring explains what changed
  • checkbox_labels.csv · price_labels.csv — current labeled examples
