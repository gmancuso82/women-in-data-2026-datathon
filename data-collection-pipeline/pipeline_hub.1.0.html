1 Collect a submission

2 Extract a paper scan

Run from a terminal, in this folder. Swap in the country's fieldmap and the scan's actual filename.
terminal
python3 extract_paper_form.1.2.py <scan.pdf> hoos_cooking_paper_form_COL.1.2_fieldmap.json hoos_cooking_form_schema.1.2.json <output_basename>
Produces <output_basename>_submissions.csv and _line_items.csv. Use the NGA fieldmap for a Nigeria form.

3 Generate a review page

Two commands: first export the crops + manifest, then turn that manifest into one HTML page a reviewer can open directly.
terminal — step 3a
python3 extract_paper_form.1.2.py --review <scan.pdf> hoos_cooking_paper_form_COL.1.2_fieldmap.json hoos_cooking_form_schema.1.2.json <review_out_dir>
terminal — step 3b
python3 build_review_tool.1.1.py <review_out_dir>/review_manifest_<form_id>.csv <review_page.html>
Then just open <review_page.html> in any browser — no terminal needed from here. See a real example: review_tool_real_scan_star.html.

4 Ingest the reviewer's corrections

After downloading the corrected CSV from the review page:
terminal
python3 extract_paper_form.1.2.py --ingest <corrected_manifest.csv> labels/
Appends to labels/checkbox_labels.csv, price_labels.csv, text_labels.csv — the growing dataset for eventually training a real classifier in place of the fixed thresholds. Current examples: checkbox_labels.csv, price_labels.csv.

What's automated vs. still manual

Checkbox/price geometry — auto-located, no manual calibration Star-mark detection — validated on a real scan, 5/5 Handwritten price OCR — unreliable, not fixed yet Header field OCR — unreliable, not fixed yet Running the scripts — needs Python + a terminal, no click-through app yet
