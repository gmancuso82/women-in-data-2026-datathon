# Women in Data Datathon 2026

## Current exploration

Our starting direction is healthy-diet affordability across countries, using a nutrition and economic lens.

The nutrition trade-off question is preserved as a backup hypothesis for later comparison.

## Project structure

- `data/raw/` — original downloaded data; do not modify it.
- `data/processed/` — cleaned, analysis-ready data.
- `notebooks/` — exploration and analysis notebooks.
- `src/` — reusable analysis code.
- `outputs/` — charts and presentation-ready results.
- `notes/` — research questions, decisions, and source notes.
